🧠 OSI Explorer

An interactive and responsive website designed to help students learn, understand, and revise the 7 layers of the OSI Model in an easy and engaging way.

🚀 Features

- 🧠 Interactive 7-Layer OSI Stack
- 🔍 Click each layer to view:
  - Layer function
  - Protocols
  - Network devices
  - PDU
- 📦 Encapsulation animation
- 🔄 Decapsulation animation
- 🎯 Exam Mode with MCQs
- 📊 Quiz score and progress tracking
- 🧩 Match the Layer mini-game
- ⚡ Quick Revision section
- 📱 Real-world example: What happens when you send a message?
- 📝 Important 2-mark and 5-mark exam points
- 🌙 Dark Mode
- 📱 Fully responsive design
- 💎 Modern and premium-looking UI

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

📚 OSI Model Layers

Layer| Name| PDU
7| Application| Data
6| Presentation| Data
5| Session| Data
4| Transport| Segment / Datagram
3| Network| Packet
2| Data Link| Frame
1| Physical| Bits

🎯 Learning Objectives

This project helps students:

- Understand the purpose of each OSI layer
- Remember protocols and devices
- Understand PDU at each layer
- Visualize encapsulation and decapsulation
- Practice networking MCQs
- Prepare for 2-mark and 5-mark exam questions
